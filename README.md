# Roach-Hunter

> 🪳 There's a cockroach. Let the robot hunt it. 🪳

An autonomous robot that detects, tracks, pursues,
and captures cockroaches using computer vision.


## How It Works

Camera → Detection → Tracking → Control → Motors
